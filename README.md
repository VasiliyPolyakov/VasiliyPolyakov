## Selected Engineering Work

### 🌐 Multi-tenant Next.js Platform

Architected a Next.js App Router rebuild of a large multi-tenant events platform.

**Scale:**

- 329 tenants
- ~2,500 active sites
- ~36,000 pages
- £102m eCommerce processed in 2025

**Key architectural work:**

- Tenant → site → page resolution
- Next.js App Router architecture
- Middleware-based routing
- Server-side rendering
- Caching and streaming
- Technical SEO and structured data
- Config-driven theming

One of the key improvements was moving tenant theming from code into configuration.

Instead of maintaining 27 tenant-specific theme packages, the platform now uses core themes with CMS-driven configuration and CSS custom properties.

This allowed the platform to grow from **19 to 329 tenants** without the styling codebase growing with it.
